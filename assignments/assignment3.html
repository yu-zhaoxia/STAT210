2. Multicollinearity via Simulation

We examine how predictor correlation inflates SEs and destabilizes coefficients via simulation. The simulation can be broken into three parts:

(1) Simulate data from the model \[ Y = 3 + 0.5X_1 + 0X_2 + \epsilon, \quad \epsilon \sim N(0,1),\] where \((X_1, X_2)\) are bivariate normal with means 0, variances 1, and correlation \(\rho\). Use \(n=100\).

(2) For each \(\rho \in \{0, 0.5, 0.7, 0.9, 0.95, 0.99\}\), simulate 1000 datasets and fit the model \(Y \sim X_1 + X_2\). Record the average estimated coefficients, their standard errors, and VIFs for \(X_1\) and \(X_2\).

(3) Summarize your results in a table with rows for each \(\rho\) and columns for average coefficients, SEs, and VIFs.

Here is the R code to perform the simulation:

Code 
set.seed(123)
library(MASS)
n <- 100
rhos <- c(0, 0.5, 0.7, 0.9, 0.95, 0.99)
results <- data.frame(rho = rhos,
                      avg_beta1 = NA, avg_beta2 = NA,
                      avg_se1 = NA, avg_se2 = NA,
                      avg_vif1 = NA, avg_vif2 = NA)
for (i in seq_along(rhos)) {
  rho <- rhos[i]
  beta1_estimates <- numeric(1000)
  beta2_estimates <- numeric(1000)
  se1_estimates <- numeric(1000)
  se2_estimates <- numeric(1000)
  vif1_estimates <- numeric(1000)
  vif2_estimates <- numeric(1000)
  
  Sigma <- matrix(c(1, rho, rho, 1), nrow=2)
  
  for (j in 1:1000) {
    X <- mvrnorm(n, mu = c(0, 0), Sigma = Sigma)
    X1 <- X[,1]
    X2 <- X[,2]
    epsilon <- rnorm(n, mean = 0, sd = 1)
    Y <- 3 + 0.5 * X1 + 0 * X2 + epsilon
    model <- lm(Y ~ X1 + X2)
    coefs <- summary(model)$coefficients
    beta1_estimates[j] <- coefs["X1", "Estimate"]
    beta2_estimates[j] <- coefs["X2", "Estimate"]
    se1_estimates[j] <- coefs["X1", "Std. Error"]
    se2_estimates[j] <- coefs["X2", "Std. Error"]
    vif_values <- vif(model)
    vif1_estimates[j] <- vif_values["X1"]
    vif2_estimates[j] <- vif_values["X2"]
  }
  
  results$avg_beta1[i] <- mean(beta1_estimates)
  results$avg_beta2[i] <- mean(beta2_estimates)
  results$avg_se1[i] <- mean(se1_estimates)
  results$avg_se2[i] <- mean(se2_estimates)
  results$avg_vif1[i] <- mean(vif1_estimates)
  results$avg_vif2[i] <- mean(vif2_estimates)
}
